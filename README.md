# Задание №9. Вариант 4. Топологическая сортировка

## Задание

Классы `ListNode`, `LinkedList` и `Stack` взяты из решения задания 7, вариант 12. Эти классы не нужно изменять.

В файле `main.py` реализовать функцию `topological_sort`. Она возвращает вершины орграфа в топологическом порядке.

Орграф задан списком списков. Вершины — индексы $0, 1, \ldots, n - 1$, где $n$ — длина внешнего списка. Элемент `graph[i]` — концы дуг, выходящих из вершины $i$. Результат содержит каждую вершину один раз. Начало каждой дуги стоит в этом списке раньше конца.

Аргумент, который не является списком списков целых номеров вершин, даёт `TypeError` с сообщением «Граф задают списком списков целых номеров вершин». Значение `bool` целым номером не считается. Номер вне диапазона от $0$ до $n - 1$ даёт `ValueError` с сообщением «Номер вершины вне диапазона».

В файле `test.py` приведены примеры. Команда расширяет набор тестов, чтобы убедиться в корректности своего решения. При проверке учитываются и тесты команды, и дополнительные проверки преподавателя, которые в репозиторий не публикуются.

## По теме

**Топологическая сортировка** $n$-вершинного орграфа присваивает вершинам номера $\{1, 2, \ldots, n\}$ так, что всякая дуга идёт от меньшего номера к большему. Такая нумерация существует тогда и только тогда, когда ориентированного цикла нет. Нумерация, вообще говоря, не единственна.

При обходе вершина последовательно проходит три состояния: неоткрытая, открытая и обработанная. Состояние меняется только в эту сторону. Неоткрытую вершину обход ещё не видел. Открытая уже увидена, но исходящие из неё дуги просмотрены ещё не все. Обработанной она становится, когда просмотрены все исходящие дуги.

В этом задании вершины хранятся как индексы $0, 1, \ldots, n - 1$. Место вершины в возвращённом списке и есть её порядок: вершина в начале списка получает номер $1$ в смысле определения выше.

# Задание №9. Вариант 3. Перестановки и коммивояжёр

## Задание

В файле `permutation_generator.py` реализовать функцию `generate_permutations`. Она выдаёт все перестановки списка `elements` по одной. Каждая следующая получается из предыдущей. Порядок выдачи лексикографический. Рекурсия не используется. Повторы и пропуски недопустимы.

Аргумент — список. Элементы могут быть любыми сравнимыми объектами. Если аргумент не список, в том числе `bool`, строка и кортеж, функция даёт `TypeError`. Пустой список даёт одну пустую перестановку.

В файле `tsp_abs_solver.py` реализовать метод `get_distance` класса `AbstractTspSolver`. Он возвращает суммарную длину маршрута: сумму длин рёбер между последовательными вершинами пути.

В файле `brute_force_tsp_solver.py` реализовать метод `get_tsp_solution` класса `BruteForceTspSolver`. Он ищет гамильтонов цикл наименьшей суммарной длины полным перебором. Для перебора вызывается `generate_permutations`, длину маршрута считает `get_distance`.

Города — индексы $0, 1, \ldots, n - 1$. Маршрут начинается и заканчивается в городе $0$ и содержит каждый город один раз. При $n = 1$ маршрут — $[0]$, расстояние $0$. Отсутствующее ребро записано как `None`. Если цикла нет, результат — `TspSolution(None, [])`. Если кратчайших маршрутов несколько, годится любой.

Класс `ErrorMessageEnum` уже реализован. Его не нужно изменять. В `AbstractTspSolver` реализуется только `get_distance`, остальные методы этого класса не изменять. Матрица проверяется до поиска. Не прямоугольная матрица чисел даёт `TypeError` с сообщением «Таблица расстояний не является прямоугольной матрицей с числовыми значениями». Отрицательное расстояние даёт `ValueError` с сообщением «Расстояние не может быть отрицательным».

В файле `test.py` приведены примеры. Команда расширяет набор тестов, чтобы убедиться в корректности своего решения. При проверке учитываются и тесты команды, и дополнительные проверки преподавателя, которые в репозиторий не публикуются.

## По теме

Перестановка — упорядочение $n$ различных элементов. Число перестановок $P_n = n!$. При этом $0! = 1$: у пустого множества одна пустая перестановка. Элементы не обязаны быть числами; для лексикографического порядка они сравнимы между собой.

Лексикографический порядок сравнивает перестановки слева направо. Из двух различных раньше идёт та, у которой в первой различающейся позиции элемент меньше. Для $\{1, 2, 3\}$ это $123,\ 132,\ 213,\ 231,\ 312,\ 321$.

**Задача коммивояжёра.** Дан орграф с $n$ вершинами и длинами рёбер $c_{ij} \ge 0$. Нужен гамильтонов цикл наименьшей суммарной длины: маршрут выходит из вершины $0$, посещает каждую другую вершину один раз и возвращается в $0$. Матрица не обязана быть симметричной. В этом задании цикл ищут полным перебором перестановок.

В записи маршрута исходная вершина стоит и в начале, и в конце: так в сумму входит ребро возврата. Сам обход содержит каждую вершину один раз.

## По теме

**Числа Фибоначчи** — элементы числовой последовательности, в которой каждое следующее число равно сумме двух предыдущих. Названы в честь средневекового математика Леонардо Пизанского (известного как Фибоначчи).

В литературе встречаются два варианта последовательности: первые два числа равны \(0\) и \(1\) либо \(1\) и \(1\).

Последовательность, заданную двумя единицами, можно интерпретировать как число пар кроликов в идеальной бессмертной популяции: в начальный момент есть одна новорождённая пара, начиная со второго месяца каждая взрослая пара ежемесячно даёт новую пару. В этой интерпретации \(N\)-е число Фибоначчи — число пар кроликов в \(N\)-м месяце.

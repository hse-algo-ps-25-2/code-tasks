# Задание №9. Вариант 5. Кратчайший путь в орграфе

## Задание

Классы `DoublyListNode`, `DoublyLinkedList` и `Queue` взяты из решения задания 7, вариант 13. Эти классы не нужно изменять.

В файле `main.py` реализовать функцию `shortest_path`. Она возвращает кратчайший по числу рёбер путь из вершины `start` в вершину `goal`.

Орграф задан списком списков. Вершины — индексы $0, 1, \ldots, n - 1$, где $n$ — длина внешнего списка. Элемент `graph[i]` — концы дуг, выходящих из вершины $i$. Путь содержит `start` и `goal`. Если эти вершины совпадают, путь состоит из одной вершины, а списки смежности всё равно проверяются.

Если пути нет, функция даёт `UnreachableVertexError` из файла `unreachable_vertex_error.py`. Его сообщение — «Вершина недостижима».

Аргумент графа, который не является списком списков целых номеров вершин, даёт `TypeError` с сообщением «Граф задают списком списков целых номеров вершин». Значение `bool` в списке смежности целым номером не считается и даёт ту же ошибку. Номер `start` или `goal`, который не является целым числом, даёт `TypeError` с сообщением «Номер вершины должен быть целым числом». Номер вне диапазона от $0$ до $n - 1$ даёт `ValueError` с сообщением «Номер вершины вне диапазона».

В файле `test.py` приведены примеры. Команда расширяет набор тестов, чтобы убедиться в корректности своего решения. При проверке учитываются и тесты команды, и дополнительные проверки преподавателя, которые в репозиторий не публикуются.

## По теме

**Кратчайший путь** из вершины $s$ в вершину $t$ — путь с наименьшим числом рёбер. Он содержит обе вершины. Если $s = t$, путь состоит из одной вершины, и рёбер в нём нет. Такой путь, вообще говоря, не единственен. Веса рёбер в этом задании не учитываются.

При обходе вершина последовательно проходит три состояния: неоткрытая, открытая и обработанная. Состояние меняется только в эту сторону. Неоткрытую вершину обход ещё не видел. Открытая уже увидена, но исходящие из неё дуги просмотрены ещё не все. Обработанной она становится, когда просмотрены все исходящие дуги.

В этом задании вершины хранятся как индексы $0, 1, \ldots, n - 1$. Возвращённый список и есть путь: первая вершина — $s$, последняя — $t$.

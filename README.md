# Задание №3. Дополнительно. Проверка генерации строк из 0 и 1

## Задание

Это дополнительное задание: за его выполнение можно получить дополнительные баллы.

В файле `main.py` реализовать функции:

- `generate_strings_naive` — генератор, его задача наивно построить все строки заданной длины из символов `0` и `1`, в которых никакие два нуля не стоят рядом: перебрать все строки из `0` и `1` этой длины и оставить только подходящие;
- `check_zero_one_strings` — валидатор, его задача проверить, что переданный набор является полным списком таких строк.

У наивного генератора $2^n$ кандидатов, фильтр отсекает строки с двумя нулями подряд. Порядок строк в возвращаемом списке не фиксируется.

Проверка набора состоит из нескольких условий. По отдельности несложно убедиться, что каждая строка состоит только из `0` и `1`, что все строки различны и что в них нет двух нулей подряд. Важно проверить полноту набора через проверку длины списка (должна совпадать с числом всех таких строк заданной длины).

Пример использования — в `main.py`.

**В этом задании** длина — целое число, не меньше $1$. Для `check_zero_one_strings` набор — список. Иначе:

- длина не целое — `TypeError`, «Длина строки не является целым числом»;
- длина меньше единицы — `ValueError`, «Длина строки меньше единицы»;
- набор не список — `TypeError`, «Набор строк не является списком».

Если длина и набор допустимы, но содержимое набора неверно (неполный набор, лишняя строка, повтор, строка другой длины, символы помимо `0` и `1`, элемент не строка), `check_zero_one_strings` возвращает `False` и не возбуждает исключение.

В файле `test.py` два набора примеров: тесты наивного генератора (в том числе проверка его результата валидатором) и тесты валидатора. Команда дополняет оба набора. При проверке учитываются и тесты команды, и дополнительные проверки преподавателя, которые в репозиторий не публикуются.

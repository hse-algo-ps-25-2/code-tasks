# Задание №5. Вариант 2. Строки из 0 и 1 и биномиальный коэффициент

## Задание

В файле `main.py` реализовать функции:

- `generate_strings` — построить все строки заданной длины из символов `0` и `1`, в которых никакие два нуля не стоят рядом;
- `binomial_coefficient_iter` — вычислить биномиальный коэффициент $C_n^k$ итеративно;
- `binomial_coefficient_rec` — вычислить $C_n^k$ рекурсивно.

Генератор нужно реализовать **двумя функциями, возвращающими наборы строк, со взаимной рекурсией**. Порядок строк в возвращаемом списке не фиксируется.

Обе функции биномиального коэффициента принимают только $n$ и $k$ и проверяют вход одинаково. Считать по правилу Паскаля

$$
C_n^k = C_{n-1}^k + C_{n-1}^{k-1}.
$$

Пример использования — в `main.py`. Файл `strings_checker.py` можно вызывать в тестах: полнота набора проверяется так же, как валидатор в задании 3+.

**В этом задании** длина — целое число, не меньше $1$. Параметры $n$ и $k$ — целые неотрицательные, $n\ge k$. `bool` не считается целым.

В файле `test.py` приведены примеры. Команда расширяет набор тестов, чтобы убедиться в корректности своего решения. При проверке учитываются и тесты команды, и дополнительные проверки преподавателя, которые в репозиторий не публикуются.

## По теме

**Взаимная рекурсия** — взаимодействие двух или более процедур, при котором они решают общую задачу, рекурсивно вызывая друг друга. Такой приём называют также косвенной рекурсией.

**Биномиальный коэффициент** $C_n^k$ — число сочетаний из $n$ по $k$. В этом задании он задаётся правилом Паскаля и базами $C_n^0 = C_n^n = 1$ (в том числе $C_0^0 = 1$). Правило Паскаля применяют при $1\le k\le n-1$.

## По теме

Неотрицательные целые решения уравнения $x_1+x_2+\dots+x_n=k$ — это способы разложить $k$ одинаковых предметов по $n$ различимым ящикам. В задаче о распределении инвестиций ящики — проекты, предметы — неделимые лоты.

Метод «звёзд и перегородок»: предмет записывают символом `*`, границу соседних ящиков — символом `|`. Чтобы разложить $k$ предметов по $n$ ящикам, нужны $k$ звёзд и $n-1$ перегородка.

**В этом задании** строка не содержит пробелов и других символов. Пустой ящик допускается: ему соответствуют две перегородки подряд, а также перегородки в начале или в конце строки.

Пример: $n=3$, $k=5$, набор $(2,1,2)$ записывается как `**|*|**`. Один ящик и $k$ предметов дают строку из $k$ звёзд без перегородок. При $k=0$ строка состоит только из $n-1$ перегородки.

Число различных строк равно числу сочетаний с повторениями:

$$\overline{C}_n^k = C^k_{n+k-1}=C^{n-1}_{n+k-1}.$$

Для $n=3$, $k=5$ получается $C^5_7=21$; для примера лекции $n=4$, $k=5$ — $C^5_8=56$.

Порядок строк в возвращаемом списке в этом задании не фиксируется: важны состав набора и формат каждой строки.

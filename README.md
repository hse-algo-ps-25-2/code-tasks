## По теме

**НОД** — наибольший общий делитель (*greatest common divisor*). Наибольшим общим делителем чисел \(a\) и \(b\) называется наибольшее число, на которое \(a\) и \(b\) делятся без остатка.

**Алгоритм Евклида** находит НОД двух целых чисел. Классический шаг: из большей величины вычитают меньшую и переходят к новой паре. Процесс повторяют, пока числа не станут равными; найденное значение и есть НОД исходной пары. Тот же алгоритм ускоряется, если вместо повторного вычитания брать остаток от деления.

**НОК** — наименьшее общее кратное (*least common multiple*). Наименьшее общее кратное чисел \(a\) и \(b\) — наименьшее число, которое делится без остатка и на \(a\), и на \(b\). Его можно вычислить, поделив произведение заданных чисел на их наибольший общий делитель.

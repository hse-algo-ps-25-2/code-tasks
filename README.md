# Задание №9. Вариант 1. Конвейерная задача

## Задание

Реализована модель предметной области для задач из теории расписаний. Классы `Task`, `StagedTask`, `ScheduleItem`, `AbstractSchedule`, а также сообщения в `errors.py` и шаблоны строк в `constants.py` входят в эту модель. Их не нужно изменять.

В файле `conveyor_schedule.py` реализовать два метода класса `ConveyorSchedule`:

- `__sort_tasks` — возвращает задания в порядке алгоритма Джонсона;
- `__fill_schedule` — заполняет расписание обоих исполнителей элементами `ScheduleItem`.

У каждого задания ровно два этапа. Исполнитель с индексом $0$ выполняет первый этап, исполнитель с индексом $1$ — второй.

Простой — `ScheduleItem` с задачей `None`. В строковом виде его название — `downtime`. Продолжительность расписания — момент окончания последнего интервала первого исполнителя. Если второй исполнитель заканчивает позже, в конец строки первого добавляется простой до этого момента.

Конструкторы уже проверяют аргументы и дают исключения из `errors.py`. Пустой список, элемент, не являющийся `StagedTask`, и задание не из двух этапов дают `ScheduleArgumentError`. Метод `get_schedule_for_executor` даёт `ScheduleArgumentError`, если индекс не целый неотрицательный или не меньше числа исполнителей.

В файле `test.py` приведены примеры. Команда расширяет набор тестов, чтобы убедиться в корректности своего решения. При проверке учитываются и тесты команды, и дополнительные проверки преподавателя, которые в репозиторий не публикуются.

## По теме

Конвейерная задача в этом задании задаётся так:

1. количество заданий произвольно;
2. каждое задание состоит из двух последовательных этапов, длительности этапов положительны;
3. задания независимы;
4. прерывание этапа не допускается;
5. работников ровно два;
6. первый работник выполняет только первый этап каждого задания, второй — только второй этап;
7. производительность работников и оплата их труда не учитываются;
8. нужно выполнить все задания за кратчайшее время.

Пусть $a_i$ и $b_i$ — длительности первого и второго этапов $i$-го задания.

Задания делят на две группы. В первую попадают задания, у которых $a_i \le b_i$, в том числе задания с равными этапами. Во вторую — остальные. Первую группу упорядочивают по возрастанию $a_i$, вторую — по убыванию $b_i$. По алгоритму Джонсона сначала выполняют первую группу в этом порядке, затем вторую.
